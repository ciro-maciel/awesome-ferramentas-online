## Метки

Каждая запись говорит, что это такое. Метки рядом помогают выбрать: официальный, когда инструмент от того, кто задаёт стандарт; открытый код, когда код опубликован; бесплатно или платно по модели использования; API и SDK по способу интеграции. Записи с меткой "от автора" сделаны Сиро Сесаром Маэлом и подчиняются тем же правилам, что и все остальные.
