## ラベル

各項目には内容が書かれています。横のラベルが選ぶ助けになります。「公式」は標準を定める側から提供されたもの、「オープンソース」はコードが公開されているもの、「無料」か「有料」かは利用形態によるもの、「API」と「SDK」は連携の方法によるものです。「"作者による"」のラベルが付いた項目は Ciro Cesar Maciel が作成したもので、他のすべての項目と同じルールに従います。
